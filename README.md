# Elm Flutter Development Bootcamp

A collection of five hands-on Flutter development projects completed during Elm's Flutter Development Bootcamp. These exercises document my progression from UI development and reactive state management to API integration, local storage, and notifications.

- **Project Period:** May 6–14, 2025 (project start dates)
- **Technologies:** Dart, Flutter, GetX, Dio, REST APIs, SQLite, Flutter Local Notifications

## Projects & Exercises

| # | Project | Project Date | Technologies |
| --- | --- | --- | --- |
| 01 | [Flutter UI Elements](./01-flutter-ui-elements/) | May 6, 2025 | Dart, Flutter, Material |
| 02 | [GetX State Management](./02-getx-state-management/) | May 7, 2025 | Dart, Flutter, GetX |
| 03 | [API Integration](./03-api-integration/) | May 11, 2025 | Dart, Flutter, Dio, REST API |
| 04 | [Local Database App](./04-local-database-app/) | May 12, 2025 | Dart, Flutter, SQLite, sqflite |
| 05 | [Reminder Notification App](./05-reminder-notification-app/) | May 14, 2025 | Dart, Flutter, Flutter Local Notifications, Timezone |

## Getting Started

Each folder is an independent Flutter project. Open the desired folder, run `flutter pub get`, then `flutter run` on a supported device. Follow the project-specific README for details.

These are educational exercises, not production applications.
